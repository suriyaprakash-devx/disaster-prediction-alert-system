# 🌍 AI-Powered Disaster Prediction & Early Warning System

An AI-powered web application that analyzes weather conditions and predicts disaster risks such as floods, cyclones, and heatwaves. The system provides real-time/near-real-time weather information, AI-based risk predictions, interactive maps, emergency alerts, and safety recommendations.

---

## 🚨 Problem Statement

Natural disasters such as floods, cyclones, and heatwaves can cause severe damage to people, infrastructure, and the environment.

One of the major challenges is the lack of easily understandable and localized disaster-risk information.

Our project aims to provide an intelligent early-warning platform that converts weather information into simple and actionable disaster-risk alerts.

---

## 💡 Our Solution

We developed a web-based AI disaster prediction and alert system that:

- 🌦️ Collects weather information
- 🤖 Uses machine learning for disaster prediction
- 📊 Calculates disaster risk levels
- 🗺️ Displays risk information on an interactive map
- 🚨 Generates emergency alerts
- 🏠 Provides emergency shelter information
- 📞 Displays emergency contacts
- 🌐 Supports English and Tamil alerts
- 🛡️ Provides disaster safety instructions

---

## ✨ Key Features

### 🌦️ Weather Monitoring

The system displays important weather parameters:

- Temperature
- Rainfall
- Humidity
- Wind Speed
